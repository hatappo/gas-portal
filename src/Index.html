      Slack

      Show saved messages in Links and incomplete To-dos in the Tasks section of Inbox & Tasks.

      Saved messages: up to 200 per connection, newest posts first, with no date limit. Results may differ from Slack’s Saved view.

      Check up to 200 To-do posts per connection from the last 31 days, newest first, including completed ones. This limit is fixed. Exclude completed To-dos without fetching replacements. Unavailable states appear as unknown. Dates refer to posting, not To-do registration; results may differ from Slack’s To-dos view.

      Slack app setup and permissions
      • Create a Slack app in the workspace you want to connect.
      • OAuth & Permissions → User Token Scopes
        • search:read — Message search
        • channels:history — Public channel messages
        • groups:history — Private channel messages
        • im:history — Direct messages
        • mpim:history — Group direct messages
        Install or reinstall the app after changing scopes.
      • Copy the User OAuth Token (xoxp-). A bot token cannot be used. Workspace approval may be required.

      These scopes can read accessible messages beyond To-dos. Tokens are stored in GAS User Properties; only the last two characters are displayed.

        GitHub

        Show assigned issues, review requests, and changes requested on your PRs from GitHub.com in the Tasks section of Inbox & Tasks.

        Use a fine-grained personal access token restricted to the repositories you need. Tokens are saved in GAS User Properties and are never shown again.

        PAT setup and permissions
        • Token name: any recognizable name (e.g. My Portal).
        • Resource owner: your account for personal use; the company organization for work.
        • Expiration: choose an expiration date.
        • Repository access: Only select repositories → select the repositories you need.
        • Permissions: Issues and Pull requests — Read-only. Metadata is included automatically.

        Organization approval may be required. The portal’s owner field is only a search filter.
